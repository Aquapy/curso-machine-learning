# Curso de Machine Learning desde cero

Curso en español para aprender machine learning paso a paso, sin saber programar. Cada módulo tiene un video en
YouTube y un cuaderno con todo el código, listo para ejecutar en el navegador sin instalar nada.

## Módulo 1 · Regresión lineal

Con un solo ejemplo, 14 vuelos con el peso del avión al despegar (toneladas) y su consumo en crucero (litros por
hora), el cuaderno recorre:

- los datos y la recta que mejor los describe,
- cómo se mide el error de esa recta (la pérdida),
- el descenso de gradiente hecho a mano, y la comprobación con la fórmula exacta,
- qué pasa al cambiar los hiperparámetros: tasa de aprendizaje, tamaño del lote y épocas,
- lo mismo con Keras,
- y cómo usar el modelo para predecir.
